## Implementation evidence

To be completed by the Executor: branch and exact base/head commits, clean-worktree state, commands,
results, build/artifact IDs and checksums, device IDs/OS, screenshots/metrics, failures and approved
waivers, deviations, and remaining risks.

## Review outcome

To be completed by an independent Reviewer with severity-ranked findings and final gate status.

## Product-owner sign-off and rollback

Record the subjective drawing/visual decision, approver/date, rollback trigger, and tested rollback
procedure. Acceptance is incomplete without this section when the change affects drawing feel,
visual identity, privacy, pricing, or release behavior.
